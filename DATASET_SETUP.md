# AD benchmark dataset

The supplied original AD benchmark file is not in this GitHub browser-upload archive because it exceeds GitHub's 25 MB browser upload limit.

1. Retrieve `data/ad.csv` from https://github.com/xiagll/OptIForest .
2. Place it at `OptIForest-main/data/ad.csv`.
3. Run the original demo from the `OptIForest-main` folder or the scripts as documented in README.md.
